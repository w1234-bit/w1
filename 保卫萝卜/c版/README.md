# 保卫萝卜 · C 语言版

原 HTML5 Canvas 版《保卫萝卜》的完整 C 语言移植，单文件 `main.c`，仅用 Win32 API + GDI 绘制，**零第三方依赖**，编译后就是一个几十万字节级的独立 exe。

## 快速开始

**方式一（推荐）**：双击 `build.bat` 一键编译（需已安装 Visual Studio 的"使用 C++ 的桌面开发"工作负载），编译完成后运行 `carrot.exe`。

**方式二（命令行）**：
```bat
cl /nologo /W3 /O2 /utf-8 /D_CRT_SECURE_NO_WARNINGS main.c /Fe:carrot.exe /link user32.lib gdi32.lib msimg32.lib shell32.lib winmm.lib
```

**方式三（MinGW / gcc）**：
```bash
gcc main.c -o carrot.exe -lgdi32 -lmsimg32 -lwinmm
```

也可以直接运行仓库里已编译好的 `carrot.exe`。

## 操作

| 操作 | 按键 |
|---|---|
| 建造武器 | 左键点武器库卡片 → 点空炮塔位 |
| 选中炮塔 | 左键点炮塔 |

## 内容一览

- **4 张地图**：草原王国 / 熔岩火山 / 冰雪王国 / 沙漠遗迹，各 12 个炮塔位
- **12 种武器**：瓶子炮、雪花塔、星星炮、火焰炮、巨龙弩、雷电磁塔、飓风塔、光棱塔、加特林、冰晶炮、毒液塔、火箭巢；每塔 3 级升级、4 种目标优先级
- **6 种怪物**：小怪、飞毛腿、大块头、魔王（开盾/狂暴/吼叫）、铁甲虫（护甲 40% 减伤）、史莱姆（死亡分裂）
- **精英怪词缀**：护盾 / 迅捷 / 再生 / 分裂 / 坚硬，金环标识、三倍金币
- **15 波经典模式 + 程序化无尽模式**
- **战前契约**：开局三选一（1★~3★），收益换代价，影响怪物血量/速度/金币/炮塔伤害
- **成就系统**：14 项成就，解锁实时横幅提示，跨局持久保存
- **冒险图鉴**：怪物 / 武器 / 成就三个分页，含各图最佳波次与全局统计
- **存档**：本局进度 + 成就/统计数据（exe 目录下 `carrot_c.sav` / `carrot_meta.sav`）
- 威胁预警红屏、连击奖励、波次结算星级、屏震、飘字、粒子特效等

## 技术实现

- Win32 + GDI 双缓冲渲染，`CreateDIBSection` 直接操作像素，`AlphaBlend`（msimg32）做半透明遮罩
- 中文界面使用 `TextOutW / DrawTextW` + 多级字体
- 高精度计时器（`QueryPerformanceCounter`）主循环，倍速拆步保证物理稳定
- 无头验证模式（开发调试用）：
  - `carrot.exe --shot out.bmp [map] [seconds]` 截图（`-1` 契约屏、`-2` 图鉴页）
  - `carrot.exe --sim out.txt [map] [seconds]` AI 自动对局并输出结果

## 与原版（index.html）的对应

数值（波次表、怪物、武器、契约）与原版一致；成就在原版 15 项基础上去掉了依赖城堡升级/附魔合成/卡包的 3 项（C 版暂未实现该子系统），新增"百战老兵/杀怪如麻"。初始金币 220、生命 10 与原版相同。

## 性能优化（第二轮）

- **GDI 对象缓存**：画刷/画笔按颜色缓存复用（320 项池 + 淘汰），取代每帧上千次 Create/Delete
- **帧率上限**：战斗 60fps、菜单/暂停 30fps，空转 CPU 占用从约 54% 降至 5%
- 源码带 UTF-8 BOM，保证 MSVC 在任何终端环境下都能正确识别中文字符串

## 体验优化（第二轮）

- 顶栏渐变背景；金币/生命变化时脉冲高亮
- 下一波倒计时改为环形进度 + 秒数
- 武器卡片：顶部高光立体感、悬停上浮、悬停即在说明区预览数值（不用先选中）
- 主菜单地图卡：悬停上浮、选中徽章、显示各图最佳波次战绩；开始按钮悬停变亮
- 记住上次的地图/模式选择（保存于 carrot_meta.sav，兼容旧档）
- 地图路径增加投影立体感、炮塔石台阴影柔化、草地主题增加草丛簇

## 已知修复记录（本轮 bug 排查）

- 塔信息面板整体偏移 (+236,+56)：右侧炮塔的面板会跑出战场被裁切 → 改用战场相对坐标绘制
- 塔面板"升级/出售/切换目标"按钮注册坐标与绘制坐标不一致，导致点不中 → 按钮登记换算屏幕坐标
- 存档把 float（累计金币）按 %d 写出，数据错乱 → 升级存档格式 v3（含本波剩余出怪队列，读档不再白拿一波结算奖励）
- 出售价显示与实际到账不一致 → 统一为 `sell_value()` 一处计算
- 精英怪金环未设置画笔/画刷，会糊出黑色扇形 → 显式金色画笔 + 空画刷
- 遮罩 alpha 未预乘、`(a<<24)` 有符号溢出 → 无符号运算 + 预乘
- 怪物弹性动画变量未生效 → 新增 `fill_ellipse` 应用于身体
- 切到后台自动暂停（防回来漏怪）、操作说明浮层防按钮穿透、鼠标离开事件正确触发、错误提示文字不再与底栏重叠
- `--sim` 模式附带存档往返自检（`save_roundtrip=1` 表示通过）
